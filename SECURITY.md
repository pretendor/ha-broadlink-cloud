# Security and privacy

Please **do not disclose vulnerabilities or credentials in public GitHub issues**. Use GitHub's **Report a vulnerability** / private security advisory feature if enabled by the maintainer. If that is not available, open an issue containing **no exploit details or secrets** requesting a private reporting channel.

Never post `.storage`, API login responses, tokens, cookies, MAC addresses or raw learnt IR/RF codes. The integration authenticates with an undocumented BroadLink EU cloud API and stores the account password inside Home Assistant configuration storage for re-login. Secure Home Assistant backups and limit file access.

This software is unofficial and is not audited or endorsed by BroadLink or Home Assistant. BroadLink may change, restrict, or disable API behavior at any time.
